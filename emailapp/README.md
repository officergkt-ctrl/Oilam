# Gmail for ZTE 2335CC

A small Android 10-compatible Gmail launcher with large, keypad-focusable menu items.
Use the phone's UP/DOWN keys and OK/ENTER to choose Inbox, Compose, Sent, Drafts,
Starred, or Search.

This lightweight companion opens Gmail in the installed web browser for mailbox
access. Compose opens the Gmail app when installed and otherwise opens Gmail's
compose page in the browser. A browser and internet connection are required.
Google sign-in takes place on Google's own page; this app does not collect or
store Google passwords or OAuth tokens.

Build with `gradle :emailapp:assembleDebug`. APK output:
`emailapp/build/outputs/apk/debug/emailapp-debug.apk`.
