# Oilam

Android launcher for selected Jewish websites. Supports Android 6.0+ and is intended for devices including ZTE Android phones.

## Included sites
- Torah Anytime
- Mostly Music
- MyZmanim
- Kol Halashon
- OU
- STAR-K
- cRc

## Build
GitHub Actions builds a debug APK on pushes to `main` or when manually started. It uses JDK 17 and Gradle 9.6.0.
